# Transparence O-Pure

Prototype citoyen mobile-first pour explorer un exemple de suivi des PFAS et le parcours de traitement de l'eau.

## Lancer le prototype

```bash
npm install
npm run dev
```

Toutes les valeurs affichées sont fictives et servent uniquement à illustrer l'interface. Elles ne décrivent pas la qualité réelle de l'eau distribuée. La recherche utilise un petit jeu de secteurs de démonstration ; la géolocalisation ne transmet pas les coordonnées à un serveur.
